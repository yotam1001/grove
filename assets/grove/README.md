# Grove identity

`logo-split-disc.svg` is the active native app mark (window, taskbar and
in-app brand), the split disc from option B in
`docs/brand/grove-options/b-split-disc.png`. `logo.svg` is the earlier
log/record variant with growth rings, still used by the README.

The older PNGs (`logo.png`, monogram and forest variants) are retained historical
concepts. They are not the active app icon and must not be selected for a release
or new shared banner.
