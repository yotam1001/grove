# Grove logo options

Four built-in Image Gen directions prepared for user review. None of these
options has been applied to the app or public banner.

| Option | Direction | Asset |
| --- | --- | --- |
| A | Woven loop: a compact interlocking ribbon symbol | [PNG](a-woven-loop.png) |
| B | Split disc: an abstract vinyl record with an offset opening | [PNG](b-split-disc.png) |
| C | Echo bloom: four soft rotating sound lobes | [PNG](c-echo-bloom.png) |
| D | Wordmark: customized lowercase type with a green notched o | [PNG](d-wordmark.png) |

Shared generation brief: a distinctive Grove music-app identity, fresh green
`#35df82`, white lowercase wordmark, neutral charcoal presentation. Avoid the
rejected G-with-leaf and literal tree designs. Use bold forms that remain
legible at app-icon sizes; no fake interface, slogan, leaf sprout, headphones,
Spotify bars, glow or 3D treatment. Each image is one independent direction.

The charcoal presentations are review artwork. Prepare transparent app icons
and final banner lockups only after a direction has been selected.
